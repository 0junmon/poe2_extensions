번역 데이터 키 검색

translations/ 의 모든 JSON 파일 키를 검색합니다. 결과는 파일의 전체 주소와 함께, 파일 구조가 배열이면 그 객체(배열 항목)를, 구조가 객체면 그 항목(id → 값)을 원본 구조 그대로 보여줍니다. 일치한 부분과 값은 굵게 표시됩니다. 중복 검색 은 같은 키가 여러 파일/테이블에 있는 그룹을 값 충돌 우선으로 보여줍니다(그룹마다 5개까지, 더보기로 펼침).
검색 상자 오른쪽 스위치는 왼쪽 = 완전 검색, 오른쪽 = 부분 일치 검색 입니다. 오른쪽 버튼 두 개는 각각 검색과 중복 검색이고, 엔터를 눌러도 검색됩니다. 그냥 더블클릭해 열어도(내장 데이터 생성 후) 동작합니다.
